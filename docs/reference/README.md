## Exit statuses

cobolwork and ironwork give each status one meaning.

| Status | Meaning |
|---|---|
| 0 | It ran. A command that gives a verdict answered yes. |
| 1 | It ran, and the verdict is no. |
| 2 | It could not run: a usage error, or an input it cannot use. Nothing was judged. |
| 3 | Undecided: it ran, and what it could not read leaves no verdict. |
| 4 | The compiler refused a program after the checks passed. |

## Options every command takes

| Option | What it does |
|---|---|
| `--help` | Print the usage text and exit. |
| `--version` | Print the version and exit. |
| `--rules-path <gitleaks>` | Print the path of the mainframe credential rules and exit. |
