# cobolwork build

This page is generated by `node diag/generate-reference.mjs` from `cobolwork capabilities`. Change the facts there, not this page.

The build gate: rank every finding, check the policy, and run the compiler only on a pass.

## Usage

```
cobolwork build <repo> [-- <compiler> <arg>...] [options]
```

## Options

| Option | What it does |
|---|---|
| `--base <ref>` | The git revision to compare against. |
| `--head <ref>` | The revision under review. The default is the working tree. |
| `--policy <file>` | An organisation's floor policy. The repository's policy can tighten it and never loosen it. |
| `--provenance <file>` | Write what was scanned, under which policy, and what was compiled. |
| `--provenance-format <cobolwork\|slsa>` | The record as cobolwork writes it, or an in-toto statement with the SLSA Provenance v1 predicate. |
| `--artifact <path[,path]>` | What the compiler produced, named as subjects of the SLSA statement. |
| `--equivalence <file[,file]>` | Ironwork equivalence statements for the programs the change edits. |
| `--allowed-signers <file>` | An OpenSSH allowed_signers file for namespace cobolwork-evidence. build refuses one inside the repository. |
| `--ironwork <path>` | After a pass, run ironwork check on every program. A program ironwork rejects exits 4; one it does not model yet leaves the build undecided. |
| `--precompile` | Translate each program that holds EXEC SQL or EXEC CICS and run the compiler on it with -fsyntax-only. |
| `--advisories <file[,file]>` | A customer's own advisory extract (JSON), loaded for this run only. |
| `--copylib <dir[,dir]>` | Copy libraries kept outside the repository, searched after the tree's own copybooks. |
| `--pds-export` | The directory holds partitioned data sets' members as files; findings name DATA.SET/MEMBER. |
| `--no-baseline` | Apply no baseline, the tree's own included. |
| `--format <json\|sarif\|md>` | Output format. The default is json. md is for advise. |
| `--out <file>` | Write to a file instead of standard output. |
| `--evidence <dir>` | Record this run in a hash-chained journal and ledger in this directory, or in COBOLWORK_EVIDENCE. |

Every command also takes `--help`, `--version`, `--rules-path`.

## Exit statuses

| Status | Meaning |
|---|---|
| 0 | Pass. |
| 1 | Fail. |
| 2 | The command could not run. |
| 3 | Undecided. |
| 4 | The compiler failed after a pass. |
