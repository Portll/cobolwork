# cobolwork evidence

This page is generated by `node diag/generate-reference.mjs` from `cobolwork capabilities`. Change the facts there, not this page.

Verify, seal, anchor or sign the evidence a run records.

## Usage

```
cobolwork evidence verify|seal|anchor|sign [statement] [options]
```

## Options

| Option | What it does |
|---|---|
| `--evidence <dir>` | Record this run in a hash-chained journal and ledger in this directory, or in COBOLWORK_EVIDENCE. |
| `--ssh-key <file>` | Sign with this SSH key. |
| `--signer <program>` | Sign with this program. |
| `--expect-key <keyid>` | The key id a seal must carry. |
| `--allowed-signers <file>` | An OpenSSH allowed_signers file for namespace cobolwork-evidence. build refuses one inside the repository. |
| `--anchor-git <repo>` | The git repository that witnesses a seal. |
| `--ref <ref>` | The ref that counts. The default is @{upstream}. |
| `--anchor-pin <commit>` | The witness commit an earlier verify reported. |
| `--push` | Push the witness. |
| `--max-unsealed <n>` | How many ledger records may follow the newest seal. |
| `--tsq <file>` | Write an RFC 3161 request. |
| `--tsr <file>` | Read an RFC 3161 response. |
| `--tsa-ca <file>` | The authority's CA certificate. |
| `--cosign-bundle <file>` | A transparency-log bundle over a seal, checked by cosign. |
| `--cosign-key <file>` | The cosign public key. |
| `--certificate-identity <id>` | The certificate identity cosign expects. |
| `--certificate-oidc-issuer <url>` | The OIDC issuer cosign expects. |
| `--trusted-root <file>` | The trusted root cosign uses. |
| `--insecure-ignore-tlog` | Do not require the transparency log entry. |
| `--out <file>` | Write to a file instead of standard output. |
| `--quiet` | Write the summary only. |

Every command also takes `--help`, `--version`, `--rules-path`.

## Exit statuses

| Status | Meaning |
|---|---|
| 0 | seal, anchor and sign: done. verify: verified and sealed. |
| 1 | verify: broken, contradicted or not sealed. |
| 2 | A usage error, or the command could not run. |
| 3 | verify: undetermined. |
