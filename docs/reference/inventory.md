# cobolwork inventory

This page is generated by `node diag/generate-reference.mjs` from `cobolwork capabilities`. Change the facts there, not this page.

List what is in a tree and what could not be read.

## Usage

```
cobolwork inventory <path> [options]
```

## Options

| Option | What it does |
|---|---|
| `--out <file>` | Write to a file instead of standard output. |
| `--quiet` | Write the summary only. |
| `--copylib <dir[,dir]>` | Copy libraries kept outside the repository, searched after the tree's own copybooks. |
| `--evidence <dir>` | Record this run in a hash-chained journal and ledger in this directory, or in COBOLWORK_EVIDENCE. |

Every command also takes `--help`, `--version`, `--rules-path`.

## Exit statuses

| Status | Meaning |
|---|---|
| 0 | The command ran. |
| 2 | A usage error, or the command could not run. |
