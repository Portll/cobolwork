# Environment variables

This page is generated by `node diag/generate-reference.mjs` from `cobolwork capabilities`. Change the facts there, not this page.

A variable that names files takes a list of paths separated by the platform's path delimiter.

| Variable | Value | What it does |
|---|---|---|
| `COBOLWORK_ABENDS` | path list | Fuzz runs from ironwork's harness. Each abend an input caused becomes a finding. Refused from inside the scanned tree. |
| `COBOLWORK_ADVISORIES` | path list | Advisory extracts loaded for the run, as --advisories. |
| `COBOLWORK_BUILDER_ID` | text | build --provenance-format slsa: the builder id the statement records. |
| `COBOLWORK_CONTROL_WORKERS` | integer | How many worker threads analyse programs. The default is one fewer than the machine's threads, at most four. |
| `COBOLWORK_COPYPATH` | path list | Copy libraries searched after the tree's own copybooks. Read before COBCPY. |
| `COBOLWORK_EVIDENCE` | directory | The evidence directory, as --evidence. |
| `COBOLWORK_EXECUTION` | path list | Reports ironwork run --coverage wrote from runs of the estate's programs. Refused from inside the scanned tree. |
| `COBOLWORK_FREE_MEMORY_MB` | megabytes | The free memory a scan may count on, for a container or shared runner whose share is not what the machine reports. |
| `COBOLWORK_MAX_SOURCE_BYTES` | bytes | A budget for source read. Files past it are counted as unread. |
| `COBOLWORK_PLI` | 0 | Set to 0 and a scan does not read PL/I. |
| `COBOLWORK_REACH` | path list | A reduced RACF unload or reachability extract. It overrides the site file's open, restricted and privileged keys. Refused from inside the scanned tree. |
| `COBOLWORK_VERIFY_REUSE` | 1 | Set to 1 and a scan checks each reused analysis against a fresh one. |
| `COBOLWORK_WITNESS` | path list | Results of tests run against findings, keyed by fingerprint. Refused from inside the scanned tree. |
| `COBCPY` | path list | Copy libraries searched after COBOLWORK_COPYPATH, as GnuCOBOL reads it. |
| `NO_COLOR` | any value | tui: use no colour. |
| `SOURCE_DATE_EPOCH` | seconds | sbom and build provenance: the time to record, so the document is the same on every run. |
