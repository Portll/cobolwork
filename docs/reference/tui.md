# cobolwork tui

This page is generated by `node diag/generate-reference.mjs` from `cobolwork capabilities`. Change the facts there, not this page.

Read a scan in the terminal, coverage first.

## Usage

```
cobolwork tui [path] [options]
```

## Options

| Option | What it does |
|---|---|
| `--report <file>` | Read a stored scan report instead of scanning. |
| `--keys <ispf\|modern>` | F3 and a command line, or Esc and letters. The default is ispf. |
| `--baseline <file>` | The judgements to apply. Without it, the tree's own baseline file. |
| `--no-baseline` | Apply no baseline, the tree's own included. |
| `--advisories <file[,file]>` | A customer's own advisory extract (JSON), loaded for this run only. |
| `--copylib <dir[,dir]>` | Copy libraries kept outside the repository, searched after the tree's own copybooks. |

Every command also takes `--help`, `--version`, `--rules-path`.

## Exit statuses

| Status | Meaning |
|---|---|
| 0 | The command ran. |
| 2 | A usage error, or the command could not run. |
