# Site file keys

This page is generated by `node diag/generate-reference.mjs` from `cobolwork capabilities`. Change the facts there, not this page.

`cobolwork.site.json` holds the facts about an estate that no repository holds. It is read from the root of the scanned tree. Its version is 1. A key opening with an underscore is a note for people.

| Key | Type | What it holds |
|---|---|---|
| `$schema` | string | The schema this file follows, for an editor. |
| `version` | integer | The site file version. A file without one is read as version 0, which holds the same keys as version 1. |
| `productionQualifiers` | array of strings | Dataset qualifiers that name production data, matched as whole leading components. |
| `productionJobPaths` | array of strings | Paths of jobs allowed to touch production. |
| `nonProductionJobPaths` | array of strings | Paths of jobs that are not production jobs. |
| `systemNames` | array of strings | Names of production systems, which the recon rules look for in source. |
| `vendorPacks` | array of strings | Vendor rule packs to load, by name. |
| `allowUnvalidatedPacks` | boolean | Load a vendor pack that has not been validated. |
| `runtimeVersions` | object | The version of each runtime the estate runs, by product, so an advisory against it can be matched. |
| `internalReaderDds` | array of strings | DDs in the CICS region's JCL that are SYSOUT=(class,INTRDR). |
| `internalReaderQueues` | array of strings | Transient-data queues that reach the internal reader. |
| `compilerOptions` | array of strings | The estate's default compiler options, as its compile procedure sets them. |
| `apfLibraries` | array of strings | APF-authorised libraries. |
| `restrictedDatasets` | array of strings | Dataset prefixes only a privileged user may read. |
| `surrogateUsers` | array of strings | Users a job may legitimately run as. |
| `superuserIds` | array of strings | Ids privileged in UNIX System Services: UID 0, or a holder of BPX.SUPERUSER. |
| `openTransactions` | array of strings | Transactions any user can start. A COBOLWORK_REACH extract overrides it. |
| `restrictedTransactions` | array of strings | Transactions a control restricts. A COBOLWORK_REACH extract overrides it. |
| `openJobs` | array of strings | Jobs any user can submit. A COBOLWORK_REACH extract overrides it. |
| `restrictedJobs` | array of strings | Jobs a control restricts. A COBOLWORK_REACH extract overrides it. |
| `privilegedTransactions` | array of strings | Transactions that run with elevated authority. A COBOLWORK_REACH extract overrides it. |
| `privilegedJobs` | array of strings | Jobs that run with elevated authority. A COBOLWORK_REACH extract overrides it. |
| `flowWalk` | object | How far the flow set walks. walkEdges: the edges one walk may examine. totalEdges: the edges every walk together may examine. minWalkEdges: what each walk still to come is reserved of the total, and the least any walk is given. Each defaults to lib/dataflow.mjs's value when absent. |
