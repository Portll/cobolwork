# cobolwork gate

This page is generated by `node diag/generate-reference.mjs` from `cobolwork capabilities`. Change the facts there, not this page.

Judge whether a patch fixed one finding and moved nothing else.

## Usage

```
cobolwork gate <repo> [options]
```

## Options

| Option | What it does |
|---|---|
| `--base <ref>` | The git revision to compare against. |
| `--head <ref>` | The revision under review. The default is the working tree. |
| `--target <fingerprint>` | The finding the patch is meant to fix, as the base reports it. |
| `--ironwork <path>` | Check the patch with ironwork check. |
| `--cobc <path>` | Check the patch with this cobc -fsyntax-only rather than ironwork. |
| `--exit-code` | Exit with the verdict rather than 0 whenever it ran. |
| `--target-only` | Judge only the target and coverage, for a revision others have changed since. |
| `--out <file>` | Write to a file instead of standard output. |
| `--evidence <dir>` | Record this run in a hash-chained journal and ledger in this directory, or in COBOLWORK_EVIDENCE. |

Every command also takes `--help`, `--version`, `--rules-path`.

## Exit statuses

| Status | Meaning |
|---|---|
| 0 | The command ran. With --exit-code: the patch passed. |
| 1 | With --exit-code: the patch failed. |
| 2 | A usage error, or the command could not run. |
| 3 | With --exit-code: undecided. |
